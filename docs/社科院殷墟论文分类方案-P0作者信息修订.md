# 社科院殷墟论文分类方案 P0 作者信息修订

本修订适用于原《社科院殷墟论文完整分类整理方案》第 1、7、8、9 页涉及“院内/院外作者”、作者字段和作者索引的内容。在建立经过专家审核的学者权威库之前，以本修订替代原方案中的静态姓名示例和院内/院外二分判断。

## 一、作者字段

1. 只按当前论文原文顺序记录作者姓名。
2. 作者字段不括注模型推断的单位、当前任职或历史身份。
3. 原文明确出现署名单位时，在备注中以“原文署名单位：”照录。
4. 原文没有单位时留空，不根据姓名、代表人物名单、其他论文或公开网页补全。
5. 原文疑似存在单位但 OCR 无法确认时，记录“作者单位待核验”。

## 二、机构关系

1. 暂停使用固定的“社科院内作者/院外作者”结论。
2. 论文署名单位、发表时任职、历史任职和当前任职是不同事实，不得互相替代。
3. 在没有学者权威库和可靠时段证据时，不判断作者当前是否属于社科院。
4. 作者及单位信息只用于检索和人工核验，不参与论文主题主分类、互见分类或候选分类。

## 三、作者索引

1. 作者索引直接从论文原文作者姓名生成，不依赖预设代表人物名单。
2. 暂不进行同名消歧、曾用名合并和跨机构关系推断。
3. 发现姓名、单位或身份错误时，保存为“作者信息反馈”，不得自动转化为通用分类规则，也不得注入其他论文的 Agent 分类上下文。

## 四、人工复核

人工复核时可选择：

- 作者姓名识别错误；
- 作者单位或身份错误。

上述反馈进入本机原始反馈记录。待未来具备学者权威库建设条件后，再由专家审核并迁移为人物资料；P0 阶段不自动学习人物身份结论。
