# 分类判定规则

## 一、层级决策树

### 1. 核心论证材料

- 以发掘过程、遗迹、墓葬、器物、地层和年代测定为核心：优先 A。
- 以甲骨材料整理、分期、文字或卜辞事类为核心：优先 B。
- 以材料重建商代政治、经济、宗教、社会和历史地理为核心：优先 C。
- 以学术史、理论方法、数字技术、科技方法、保护展示为核心：优先 D。

不要按研究年代直接分类。题名出现“商代”不等于 C；必须判断论文主要贡献落在材料整理、考古事实还是历史解释。

### 2. 文献性质

一手资料优先：新发掘简报、正式报告、材料著录、校勘、缀合、图录和数据库整理，应归相应资料类。论文若只是引用这些材料来形成历史或制度结论，则按研究问题归类。

### 3. 主要研究问题

用一句话写出“作者用什么材料，解决什么问题，主要新结论是什么”。主分类对应主要新结论，而不是出现频率最高的名词。

### 4. 三级类与互见

主类只能有一个。互见必须满足：论文对该次主题有独立问题、方法和结论；仅在背景、综述或一两处例证中出现的不互见。最多三个互见。

## 二、社科院特殊规则

- 作者单位：只按论文原文署名记录。无法确认时不根据姓名记忆猜测。
- 特殊材料：花东 H3、小屯南地、西北冈王陵、铸铜遗址必须进入核心材料、地点或关键词索引。
- 专著析出文献：可独立署名引用的章节按章节主题分类，不归“专著”。
- 资料整理/研究论述：首次公布、校勘、著录属于基础材料；历史考证、文字考释、制度分析属于研究论述。
- 排序和编号：单篇处理无法知道总库顺序时，“编号”留空，不生成虚构序号。

## 四、其他高频边界

- B12 甲骨缀合/残辞复原 与 D23 AI 甲骨复原：人工材料整理和传统方法归 B12；算法、模型和数字复原方法是核心归 D23。
- B14 拓片数字化 与 D25 数据库知识图谱：单批拓片、照片和库房整理归 B14；数据库结构、关联检索和知识图谱方法归 D25。
- A41-A45 年代学 与 B21-B24 甲骨断代：考古文化、地层和绝对年代归 A4；卜人组、字体、贞人和卜辞组类归 B2。
- D41-D43 与专题类：书评、札记、会议综述以文献类型为主要贡献时归 D4；题名虽为“札记”但形成完整文字考释时可归 B31-B34。

## 五、证据门槛

主分类至少两条逐字证据：一条说明材料和研究目标，一条说明主要结论。题名可以作为辅助证据，但不能是唯一证据。引文必须位于指定 PDF 页；OCR 无法确认的字用原 OCR 文本，不自行修正文句后再作为“逐字引文”。
