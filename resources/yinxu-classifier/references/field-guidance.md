# A-Z 字段填写指南

## 基础与分类字段

| 字段 | 填写要求 | 证据与禁止事项 |
|---|---|---|
| 编号 | 已有馆藏号则照录；否则留空 | 不得虚构“大类+顺序号” |
| 作者 | 只按原文顺序记录作者姓名，不混入单位 | 不根据姓名、静态名单或当前任职猜测社科院身份 |
| 题名 | 完整题名 | 取自首页、页眉或书目信息 |
| 研究领域 | 甲骨学/殷墟考古/商代历史/宗教思想/科技考古等能概括论文研究对象的领域 | 以论文题名、摘要和核心论证为据；不得仅照分类代码机械填写 |
| 期刊名称 | 期刊、集刊、报告或会议论文集名称 | 优先核查首页及每页页眉、页脚、页角；无法确认时留空 |
| 发表时间 | 原文明确的年、月或日期 | 按原文照录，如“2024年”或“2024年6月”；不得推测 |
| 期号 | 原文明确的卷、期、辑或册 | 按原文照录，如“2024年第3期”或“第12辑”；不得把 PDF 页码填入此字段 |
| 出处 | 对期刊名称、发表时间、期号和印刷页码的兼容性汇总 | 优先由上述字段汇总；缺项留空，不补猜 |
| 文献类型 | 期刊论文/考古简报/发掘报告/集刊论文/会议论文/学位论文/书评/学术札记 | 以来源和体例判断 |
| 一级分类 | 由程序根据主分类代码覆盖 | Agent 仍填写预期路径供差异审计 |
| 二级分类 | 由程序根据主分类代码覆盖 | 同上 |
| 三级细分类 | 由程序根据主分类代码覆盖 | 同上 |
| 核心材料载体 | 甲骨/青铜器/陶器/建筑基址/墓葬/人骨/动物骨骼/多学科检测/其他明确材料 | 选择支撑核心结论的材料 |
| 核心研究时段 | 只记录论文明确讨论的王期、甲骨分期或殷墟文化期 | 不因研究对象是殷墟自动填写 |
| 出土地点 | 使用论文明确地点 | 花东H3、小屯南地、西北冈等保留规范写法 |
| 关键词 | 3-5 个，分号分隔 | 覆盖材料、问题、地点/时期；避免“研究”“论文”等空词 |

## AI 数字化复原字段

这些字段只有论文正文、图版说明或数据说明提供直接依据时才能填写；仅凭题名、领域常识或对同类材料的想象必须留空，字段分数不高于 0.4。

| 字段 | 允许值或格式 |
|---|---|
| 视觉素材等级 | S级可训练 / A级可参考 / B级仅语义 / C级禁用 |
| 可复原维度 | 单视角 / 三视图 / 平立剖全套 / 原始点云数据 |
| 几何精度等级 | 毫米级实测 / 厘米级推算 / 示意级复原 |
| 生图用途分类 | 器物复原 / 场景复原 / 祭祀再现 / 服饰复原 / 建筑还原 / 工艺复原 |
| 风格锚点 | 写实考古风 / 博物馆插画 / 纪录片质感 / 国风插画 / 学术线稿 |
| 可动态化场景 | 祭祀仪式 / 铸铜工艺 / 建造过程 / 车马行进 / 占卜动作 / 无可动态化 |
| 学术可信度 | 一级实证 / 二级推论 / 三级假说 / 四级演绎 |
| 适用工具链 | SD / Midjourney / Runway / Pika / NeRF / 3DGS / Blender；只记录论文明确数据能力可支持的工具 |
| ControlNet条件 | Canny / Depth / Seg / Pose / Normal / 无条件 |
| 训练数据价值 | 可做LoRA训练 / 可做数据集扩充 / 仅作推理参考 / 不可用 |
| 版权使用范围 | 社科院自有 / 公有领域 / 需授权 / 仅限内部研究 |
| 数字化成果类型 | 2D静态 / 2.5D视差 / 3D低模 / 3D高模 / 视频 / VR/AR交互 |

## 系统字段

| 字段 | 填写要求 |
|---|---|
| 文件路径 | Agent 填写 `source/original.pdf`；程序会强制覆盖 |
| 备注 | 100-300 字核心观点摘要；原文明确单位时用“原文署名单位：”照录；OCR 不清时写“作者单位待核验”；另记录特殊材料、互见理由、推测性字段和缺失书目信息 |

## 字段评估

每个字段必须输出 `score`、`reason`、`evidence`：

- 0.85-1.00：原文明确、证据可逐字核对；
- 0.60-0.84：多处信息组合或存在轻微 OCR 风险；
- 0.40-0.59：只有间接信息，必须人工核对；
- 0-0.39：缺失、冲突或无法从当前文本证明。

分类路径和文件路径由程序确定，Agent 的字段评估用于审计。空字段仍需输出评估对象，说明为什么留空。
