# 分类正反例

以下是判别方式示例，不是可直接复制的论文事实。

## A13 与 D21

- “无人机测绘发现宫殿区围沟走向，主要结论是都邑布局” -> A13；摄影测量只是工具。
- “比较三种点云重建算法在殷墟建筑复原中的误差” -> D21；方法和模型是研究对象。

## A24 与 D26

- “对某祭祀坑人骨进行同位素分析，以识别个体来源和牺牲群体” -> A24。
- “构建殷墟多类材料的锶同位素基线并讨论方法适用性” -> D26。

## A21 与 C21

- “某墓出土青铜爵的器型、纹饰和合金组成” -> A21。
- “晚商铸铜作坊的生产组织、矿料供应和技术体系” -> C21。

## B41 与 C31/C32

- “整理某组卜辞中的周祭辞例及祭名” -> B41。
- “依据多组卜辞重建商代天帝与王权的神权结构” -> C31，B41 可互见。
- “讨论先祖称谓反映的祖先崇拜观念” -> C32；若核心是字词和辞例分类则仍为 B 类。

## A3 与 C34

- “比较王陵、贵族墓和平民墓的墓制与等级差异” -> A35 或更具体的 A31/A32。
- “以墓葬材料讨论商代死后世界和灵魂观念” -> C34，相关墓葬类可互见。

## B42 与 C41/C42

- “汇集某方国征伐卜辞并整理辞例” -> B42。
- “考证某一卜辞地名的地望和疆域归属” -> C41。
- “综合多个方国的位置重建四土地理格局” -> C42，B42 可互见。

## 资料整理与研究论述

- 首次公布一批甲骨照片、释文并校勘编号 -> B11。
- 在已公布材料基础上缀合残片 -> B12。
- 使用这些材料讨论一个新字的字形和词义 -> B31。
- 年度发掘简报即使包含初步解释，主要贡献仍是发掘记录 -> A11/A12。

## 不应分类或应降置信度

- 只有题名和一页残缺 OCR，无法确认主要材料与结论：保留候选、记录冲突，不用常识补齐。
- 论文只提到“采用数字技术”，没有方法或数字成果细节：不能直接归 D21/D22。
- 正文没有图版质量、比例尺、视角、版权信息：视觉与训练字段全部留空并标红。
